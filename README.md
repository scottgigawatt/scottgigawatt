# Great Scott! ⚡

Hi, I'm **Scott**. I build self-hosted tools for media servers, Docker, and
Synology—usually because I got tired of doing something by hand and decided to
make the solution everyone else's problem.

My natural habitat is somewhere between a tidy Compose file and a cron job I
definitely remember creating.

## What I'm building

- [**Plundarr**](https://github.com/scottgigawatt/plundarr) generates complete,
  validated Docker Compose media stacks—including the Synology and media-server
  tooling that used to live in Duplex—without turning setup into a weekend-long
  archaeological dig.
- [**Privateerr**](https://github.com/scottgigawatt/privateerr) packages PIA,
  WireGuard, port forwarding, and Gluetun into one small, seaworthy container.

I care about the unglamorous stuff that makes self-hosted software pleasant:
sane defaults, reproducible deployments, clear docs, and error messages that
tell you what actually broke.

## The workbench

**Docker & Compose · Python · Bash · TypeScript · Ansible · GitHub Actions**

I develop on macOS, run almost everything on Linux, and treat YAML as both a
configuration format and a recurring character-building exercise.
