## What I'm building

### Plundarr 🏴‍☠️

[**Plundarr**](https://github.com/scottgigawatt/plundarr) turns the media apps
you choose into a complete Docker Compose deployment. It sorts out dependencies,
writes the Compose and environment files, and validates the result before launch.
It can build movie and TV automation stacks, standalone Plex or Jellyfin setups,
or a custom fleet for Docker and Synology Container Manager.

You choose the cargo; Plundarr handles the rigging. Much less archaeological
digging through abandoned Compose snippets at 2 a.m.

### Privateerr ⚓

[**Privateerr**](https://github.com/scottgigawatt/privateerr) puts Private
Internet Access's official connection scripts into a small Docker image. It
generates a WireGuard configuration and the server details that Gluetun—or
another compatible VPN client—needs to connect, including the awkward bits
required for port forwarding.

Privateerr is not the VPN client. It does the paperwork, hands Gluetun the map,
and leaves before networking gets emotionally complicated.

I care about the unglamorous stuff that makes self-hosted software pleasant:
sane defaults, reproducible deployments, clear docs, and error messages that
tell you what actually broke.
